# Creating-User-Accounts

   **Objective:  Create user accounts with specific attributes**

1. Starting with HR as an example, click New > User, then fill in the user details (e.g., John Doe with username: jdoe)
   
2. Click Next, then enter a password for this user.
   
3. On the user go to properties> add description (e..g HR Staff)
  
4. You can create more users for IT and Accounting OU following steps above.

6. Do the same for another user in the HR OU
7. Add the user in the OU IT to the Domain Admins Group
